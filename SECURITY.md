# Security and privacy

[简体中文](SECURITY.zh-Hans.md)

Do not post private recordings, credentials, host/device configuration or exploitable details in a public issue. Use GitHub's private vulnerability reporting if it is enabled for this repository; otherwise contact the repository owner privately before disclosing sensitive details. A response-time SLA is not currently offered.

The workspace is trusted local input, not a sandbox for hostile recording bundles. Recovery ownership markers are not authentication. Only authorize folders you trust. See [README](README.md) for Apple's optional online speech processing and data storage. Provide synthetic reproductions, OS/app versions and redacted logs when reporting faults. No telemetry or crash upload is implemented by this repository.
